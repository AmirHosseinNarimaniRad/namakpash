Does browser storage survive on this device?

A marker is written into four storage backends on the first visit. Every later visit checks whether it is still there. If Safari evicts the data, this page is where it shows up.

…reading storage

Checking what is on this device.

The marker

Four backends, because they are not evicted as one: a browser may drop some and keep others. OPFS is the one a SQLite database would live in.

Storage policy

Requesting persistence is the API that asks the browser not to evict this origin. What it answers on iOS is one of the things being measured.

How to run the test

  1. Open this page once in Safari and leave it — that writes the marker.
  2. Add it to the Home Screen from the share sheet, open it from there once, and leave that too. Home-screen web apps are exempt from the seven-day rule; a plain tab is not.
  3. Do not open either for at least eight days, then open both and read the number at the top.

The tab and the home-screen app share one origin, so they share the marker — the difference being measured is how the browser treats each.
